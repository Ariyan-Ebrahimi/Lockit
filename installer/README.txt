LockIt Windows Installer
========================

1. Install Python 3.12 (x64).
2. Install Inno Setup 6.
3. Double-click build_installer.bat from the project root.
4. The final installer will be created in:
   installer_output\LockIt-Setup-0.1.0.exe

The installer:
- installs LockIt into Program Files\LockIt
- creates a Desktop shortcut automatically
- creates a Start Menu shortcut
- adds a normal Windows uninstaller
- optionally launches LockIt after installation
